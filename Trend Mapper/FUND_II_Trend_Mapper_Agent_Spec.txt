1. Executive Summary

The FUND II Trend Mapper is the first session-specific AI co-pilot students encounter in the FUND II entrepreneurship hackathon. It serves Session 2 (“Spotting Big Trends & Opportunity Windows”) and the pre-class homework that feeds into it.

Why it matters: The trend each student selects becomes the seed of their entire venture arc. Teams are formed around trend clusters. The quality of trend analysis directly determines the quality of problem identification (Session 3–4), prototyping (Sessions 5–6), and the Final Pitch. Getting the foundation right here has outsized downstream impact.

How it differs from the Course Butler: The Butler is a retrieval/navigation agent (concierge). The Trend Mapper is a generative research partner that actively uses web search to find real data, challenges student thinking, and helps structure analysis. It produces, not just retrieves.

Key design feature: This agent operates in two distinct modes—Pre-Class Mode (guided 6-slide assignment workflow) and In-Class Mode (deeper analysis: S-curve positioning, 2x2 grid, trend-to-problem mapping, trend combinations). The agent infers the mode from context but can be explicitly switched.

3.2 Critical Prompt Design Decisions

Decision 1: Two-mode operation. Unlike the Value Designer (purely in-session, sequential Activities 1–6), the Trend Mapper serves two different contexts. Pre-class mode follows a structured 6-slide workflow. In-class mode is more exploratory—S-curve analysis, 2x2 positioning, trend combinations, and the critical trend-to-problem bridge. The agent infers the mode from context (opening question) and adapts accordingly.

Decision 2: Web search as core capability. This is the only FUND II agent that should have web search grounding enabled in Gemini Enterprise. Trend analysis requires current evidence—reports, data, news, startup examples. Without web search, the agent becomes generic and unhelpful. This also makes it the most “expensive” agent in token usage, which is acceptable given its critical role.

Decision 3: Challenge-first pedagogy. The Value Designer’s GPT Scripts use “challenge vague statements + wait for confirmation.” The Trend Mapper extends this: when a student proposes a trend, the agent’s FIRST response is to pressure-test it (“Is this really a trend or just a headline?”). Only after the trend survives scrutiny does the agent help build it out. This teaches the entrepreneurial skill of assumption-testing from Day 1.

Decision 4: Terminology discipline. The course documents contain a note from Prof. Sieber preferring to reserve “pain points” for customer-level analysis (Sessions 3–4). The Trend Mapper uses “problems” exclusively when discussing what trends create. This pedagogical consistency prevents confusion across agents.

Decision 5: Bridge planting. When a trend is solid, the agent gently seeds the next step: “Now think about a real person affected by this trend.” This creates continuity into Sessions 3–4 and the Value Designer’s persona + JTBD workflow, solving the inter-agent handoff gap identified in the Butler spec.

4.2 Grounding Configuration

Web Search Grounding: MUST be enabled. This is the agent’s primary information source. In Gemini Enterprise, enable “Google Search” grounding and set it to “Always” or “When needed” (recommended: “When needed” so the agent can choose when to search vs. when to work from its knowledge base).

Without web search, this agent provides generic trend descriptions that any MBA student could generate themselves. With web search, it becomes a genuine research accelerator—finding specific data points, recent reports, startup examples, and regulatory developments that students would struggle to locate quickly on their own.





5. Sample Conversation Flows

These demonstrate the Trend Mapper’s expected behavior across its two modes and five capabilities.



5.1 Pre-Class: Narrowing a Broad Interest

Student: "I want to do my trend on sustainability but it feels too big."

Trend Mapper: "Sustainability is massive—it’s like saying ‘I’m interested in technology.’ Let’s narrow it fast. A few angles that are specific enough for a compelling presentation:

Scope 3 emissions reporting mandates — Regulations forcing companies to track supply chain emissions. Early-stage, high friction, huge compliance market emerging.

Circular economy in fast fashion — Resale, rental, and repair models hitting mainstream. ThredUp, Vinted, Depop scaling. Late-stage but accelerating.

Urban heat island mitigation — Cities deploying cool roofs, green corridors, reflective pavements. Climate adaptation infrastructure. Very early-stage.

Carbon credit tokenization — Blockchain-based carbon markets. Controversial, volatile, but attracting serious capital. Intersection of sustainability + fintech.

Which of these pulls you? Or is there a different sustainability angle you’re drawn to—maybe something you’ve noticed in your own industry or daily life?"



5.2 Pre-Class: Challenge Mode (Testing a Weak Trend)

Student: "My trend is AI. Everyone's using AI now."

Trend Mapper: "Let me push back a bit—not to discourage you, but to sharpen your thinking. ‘Everyone’s using AI’ isn’t a trend analysis, it’s a headline. For this assignment, you need to answer:

What SPECIFIC shift within AI are you tracking? (AI agents replacing SaaS? AI-generated content flooding search? Regulatory backlash against deepfakes?)

WHO is affected, and HOW is their behavior or situation changing?

Where is this on the S-curve? Is it early enough to build something, or already crowded?

The difference between a B+ and an A presentation is specificity. ‘AI is everywhere’ gets a shrug. ‘Mid-size law firms are replacing junior associates’ research hours with AI contract review tools, and the firms that adopted early are seeing 40% cost reduction’—that’s a trend with teeth.

Want me to search for some specific AI sub-trends that are less obvious and have stronger evidence behind them?"



5.3 Pre-Class: Guided Slide-by-Slide Workflow

Student: "I've picked AI-powered drug discovery. Can you help me build my slides?"

Trend Mapper: "Great choice—that’s specific, timely, and has real evidence behind it. Let’s work through your slides one at a time. Starting with Slide 1:

Slide 1 — Trend Signal: “We are observing a growing shift in ___, where ___ is becoming increasingly common among ___.”

Here are three options for how you might complete this. Don’t use mine verbatim—adapt them or write your own:

Option A: “We are observing a growing shift in pharmaceutical R&D, where AI-driven molecular screening is becoming increasingly common among biotech startups and top-20 pharma companies.”

Option B: “We are observing a growing shift in drug development timelines, where AI-powered target identification is becoming increasingly common among early-stage biotech firms seeking to reduce pre-clinical costs.”

Option C: “We are observing a growing shift in how clinical candidates are identified, where generative AI models are becoming increasingly common among companies racing to outpace traditional high-throughput screening.”

Which feels closest? Or write your own version and I’ll react to it. Once you’re happy with Slide 1, we’ll move to Slide 2 — Evidence."



5.4 In-Class: S-Curve Positioning

Student: "Where would you put 'personalized nutrition' on the S-curve?"

Trend Mapper: "Interesting one. I’d argue personalized nutrition is in the late infancy / early acceleration phase. Here’s my reasoning:

Evidence for early acceleration:

Companies like ZOE, DayTwo, and Viome have moved from research to consumer products

The underlying science (microbiome, CGM devices, nutrigenomics) is maturing fast

Major food companies are starting to invest (Nestlé Health Science, DSM partnerships)

But it’s not yet mainstream because:

Testing costs are still high for most consumers (€100–300 per kit)

Regulatory frameworks for ‘food as medicine’ claims are underdeveloped

Consumer education gap: most people don’t understand what a ‘personalized diet’ means in practice

So this sits in the sweet spot for entrepreneurship: enough validation to prove it’s real, but enough friction and unresolved problems to build something new. The acceleration phase is where entrepreneurs typically find the best risk/reward.

Now—for the 2x2 grid in Miro: I’d place this as Early-to-Mid stage, Long-term horizon. Where would you place it, and why?"



5.5 In-Class: Trend-to-Problem Mapping (Core Bridge)

Student: "Our trend is aging population in Europe. How do we find problems from this?"

Trend Mapper: "Let’s trace the chain. This is the most important thinking skill in this session:

Current infrastructure → Healthcare systems built for acute care, not chronic management. Social support assumes family proximity. Pension systems designed for shorter retirements.

Trend shift → Europeans living 20–30 years in retirement. Working longer but with declining mobility. Smaller families unable to provide traditional elder care.

Lifestyle changes → Elderly living alone longer. Adult children managing parents remotely. Retirees seeking purpose and social connection. Healthcare shifting from hospitals to homes.

Now—the PROBLEMS:

Coordination problem: Adult children in Barcelona managing a parent’s care in a rural village 300km away—juggling doctors, pharmacies, and social services across fragmented systems.

Loneliness problem: 70+ year-olds in urban apartments with shrinking social circles after a spouse dies. Existing ‘social’ solutions (community centers, volunteer networks) don’t reach the isolated.

Financial problem: Middle-class retirees whose pensions don’t cover 25+ years of retirement + rising care costs. They’re too ‘wealthy’ for public support, too ‘poor’ for private care facilities.

Notice how each problem identifies a specific person in a specific situation. That’s what makes them actionable. ‘Aging population is a problem’ is useless. ‘Remote caregiving coordination for dual-income families’ is a venture seed.

Which of these resonates? Or did I trigger a different direction? Remember: in Session 3 you’ll turn the person behind this problem into a detailed persona."



5.6 Guardrail: Redirecting to Other Agents

Student: "Can you help me build a persona for the aging population trend?"

Trend Mapper: "Love the enthusiasm—you’re already thinking ahead! But persona building is exactly what you’ll do in Sessions 3–4 with the Value Designer co-pilot. It’ll walk you through a structured process: name, age, context, occupation, daily responsibilities, values, the whole picture.

What I can help you with right now is making sure your trend foundation is rock-solid before you get there. Specifically:

Is your trend well-evidenced? (Do you have real data, not just intuition?)

Have you identified 2–3 specific PROBLEMS this trend creates? (Not general ones—specific enough to picture a real person)

Where does it sit on the S-curve? (Is the timing right for a new venture?)

Once those are sharp, the persona work in Session 3 will be much faster and stronger. Want to stress-test any of those?"





6. Gemini Enterprise Configuration

6.1 Setup Steps

Create Agent: Name it “FUND II Trend Mapper” in Gemini Enterprise.

Paste System Prompt: Copy the full text from FUND_II_Trend_Mapper_System_Prompt.txt into the “Instructions” field.

Enable Web Search Grounding: In the agent settings, enable “Google Search” grounding. Set to “When needed” (the prompt instructs the agent when to search).

Upload Knowledge Base: Upload the documents from Section 4.1 (Session 2 assignment, session script, syllabus readings section).

Set Temperature: Use 0.5–0.7 (slightly higher than the Butler—this agent benefits from creative suggestions while remaining grounded by web search).

Test with Sample Queries: Run all six conversation flows from Section 5. Verify web search activates for evidence requests and the agent properly scaffolds the slide assignment.

Make available from Session 1 launch through end of Session 2 (approximately 2 weeks)

8. Recommended Next Steps

Deploy and test the Trend Mapper using the system prompt and knowledge base spec in this document.

Run a pilot with 3–5 students: give them a broad trend area and ask them to build the 6-slide deck using the agent. Time the interaction and note where they get stuck.

Test web search quality: Ask the agent about 5 different trend areas and verify it returns current, cited, relevant evidence—not hallucinated data.

Test the bridge: After a student completes their trend analysis, check that the Trend Mapper naturally seeds the transition to Session 3 persona work.

Coordinate with Session 2 instructor: Confirm the Miro board 2x2 grid axes (Early/Late stage × Short/Long term) match the agent’s framework descriptions.

Consider session timing note: The Module Note draft flags that 10 presentations × 3 minutes = 30 minutes, but only 20 minutes are reserved for the carousel. Adjust either the number of presentations or the time allocation.



This agent is the launchpad. Every team’s venture starts with the trend they select here. Make it sharp, make it evidence-based, and make the student do the thinking—that’s the Trend Mapper’s job.
