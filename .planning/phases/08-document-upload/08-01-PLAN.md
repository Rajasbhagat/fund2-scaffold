**Change A — Add `uploadedFiles` relation to the `Project` model:**

```prisma
model Project {
  id            String         @id @default(cuid())
  name          String
  createdAt     DateTime       @default(now())

  messages      Message[]
  uploadedFiles UploadedFile[]
```

**Change B — Add the UploadedFile model** at the bottom of the schema file, after the AppSettings model:

```prisma
model UploadedFile {
  id            String   @id @default(cuid())
  projectId     String
  filename      String
  originalName  String
  mimeType      String
  extractedText String
  createdAt     DateTime @default(now())
  project       Project  @relation(fields: [projectId], references: [id], onDelete: Cascade)

  @@index([projectId])
}
```

Field purposes:
- `filename` — stored filename on disk (UUID-based, e.g. `a1b2c3d4.pdf`)
- `originalName` — original user-visible filename (e.g. `Customer Personas.pdf`)
- `mimeType` — MIME type string for routing to correct extractor
- `extractedText` — full plain text output from the extractor (stored in DB, not on disk)
