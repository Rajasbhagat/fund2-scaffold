    **File 1: `src/lib/landing-prompt/system-prompt.ts`**

    Create this file with `import 'server-only'` at the top (same pattern as `src/lib/slides/` modules).

    Export a single constant `LANDING_PROMPT_SYSTEM` (type `string`) containing the full system prompt. The prompt must instruct Gemini to:

    1. Parse messages labeled with `[TREND-MAPPER]`, `[VALUE-DESIGNER]`, and `[SPI]` prefixes
    2. Extract venture details from each agent's contributions
    3. Output exactly these 7 markdown sections in order:
       - `## [VENTURE NAME] — Landing Page Build Brief`
       - `### 1. Venture Overview` (2-3 sentences: what it does, why it exists)
       - `### 2. Target User` (demographics, behaviors, JTBD from Value Designer)
       - `### 3. Core Value Proposition` (primary benefit, differentiator, solution name + slogan from VD Activity 6)
       - `### 4. Page Sections & Copy Guidance` (ordered list: Hero, Problem, Solution, Features, Social Proof/"Why Now", Call to Action — each with headline + body copy guidance)
       - `### 5. Feature List` (bullet list from Digital Density Canvas: Automation, Anticipation, Coordination, Personalization)
       - `### 6. Design Aesthetic` (tone, color palette suggestion, typography mood)
       - `### 7. Technical Scaffold` (routing structure, 3-5 component names, tech stack suggestion)
    4. Include instructions: if information is missing for a section, write a placeholder noting what's missing (e.g., `[Missing: venture name — ask the student to provide it]`)
    5. Never invent venture details not present in the conversation
    6. Keep total output under 2000 words
    7. Format as clean markdown suitable for direct paste into Bolt, Lovable, Cursor, or v0

    Use the exact prompt text from the RESEARCH.md "System Prompt Template" section as the base.

    **File 2: `app/api/landing-prompt/[projectId]/route.ts`**

    Create directory `app/api/landing-prompt/[projectId]/` and the route file.

    Structure (follow the slide route pattern exactly):
    ```
    export const runtime = 'nodejs';
    export const maxDuration = 60;
    ```

    Imports:
    - `generateText` from `'ai'` (NOT `generateObject` — it is deprecated)
    - `createVertex` from `'@ai-sdk/google-vertex'`
    - `NextResponse` from `'next/server'`
    - `prisma` from `'@/lib/prisma'`
    - `LANDING_PROMPT_SYSTEM` from `'@/lib/landing-prompt/system-prompt'`

    Vertex init (same as slide route):
    ```typescript
    const vertex = createVertex({
      project: process.env.GOOGLE_CLOUD_PROJECT,
      location: process.env.GOOGLE_CLOUD_LOCATION ?? 'us-central1',
    });
    ```

    POST handler signature (Next.js 16 — params is a Promise):
    ```typescript
    export async function POST(
      _request: Request,
      { params }: { params: Promise<{ projectId: string }> }
    )
    ```

    Handler logic:
    1. `const { projectId } = await params;`
    2. Load ALL messages: `prisma.message.findMany({ where: { projectId }, orderBy: { createdAt: 'asc' }, select: { role: true, content: true, agentType: true } })`
    3. If `dbMessages.length === 0`, return `NextResponse.json({ error: 'No conversation found for this project.' }, { status: 422 })`
    4. Map messages to AI SDK format — label assistant messages with agent type prefix:
       ```typescript
       const messages = dbMessages.map((m) => ({
         role: m.role === 'user' ? ('user' as const) : ('assistant' as const),
         content: m.agentType
           ? `[${m.agentType.toUpperCase()}]: ${m.content}`
           : m.content,
       }));
       ```
    5. Call `generateText({ model: vertex('gemini-2.5-flash'), system: LANDING_PROMPT_SYSTEM, messages })`
    6. Return `NextResponse.json({ prompt: result.text })`
    7. Wrap in try/catch — on error return `NextResponse.json({ error: message }, { status: 500 })`

    Do NOT use `Output.object()` or any Zod schema. Access `result.text` (NOT `result.output`).
