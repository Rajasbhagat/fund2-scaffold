  <action>
    Create `src/components/LandingPromptModal.tsx` as a `'use client'` component.

    **Props interface:**
    ```typescript
    interface LandingPromptModalProps {
      projectId: string
      onClose: () => void
    }
    ```

    **State machine:** `type ModalState = 'loading' | 'done' | 'error'`
    - Component starts in `'loading'` state (NOT idle — generation starts on mount)
    - `promptText: string` — holds the generated prompt
    - `copyLabel: string` — starts as `'COPY TO CLIPBOARD'`, changes to `'COPIED!'` for 2s after copy
    - `errorMsg: string` — error message to display
    - `abortController: AbortController | null` — for cancel support

    **Auto-trigger on mount:**
    Use `useEffect` with empty dependency array to call `generate()` on mount. The `generate` function:
    1. Create `new AbortController()` and store in state
    2. `fetch('/api/landing-prompt/${projectId}', { method: 'POST', signal: controller.signal })`
    3. On success (`res.ok`): parse JSON as `{ prompt: string }`, set `promptText`, set state to `'done'`
    4. On non-ok response: parse JSON as `{ error?: string }`, set `errorMsg` to `json.error ?? 'Generation failed — try again'`, set state to `'error'`
    5. On catch: check `err.name === 'AbortError'` — if so, call `onClose()` silently (user cancelled). Otherwise set `errorMsg` and state to `'error'`
    6. In `finally`: set `abortController` to `null`

    **Cancel handler:**
    `handleCancel`: calls `abortController?.abort()` then `onClose()`

    **Copy handler:**
    `handleCopy`: calls `navigator.clipboard.writeText(promptText)`, sets `copyLabel` to `'COPIED!'`, then `setTimeout(() => setCopyLabel('COPY TO CLIPBOARD'), 2000)`

    **Retry handler:**
    `handleRetry`: resets state to `'loading'`, clears `errorMsg`, calls `generate()` again

    **JSX structure (HUD theme):**
    ```tsx
    {/* Backdrop — fixed full-screen overlay */}
    <div className="fixed inset-0 z-50 bg-black/70 flex items-center justify-center p-4">
      {/* Panel */}
      <div className="bg-hud-fg border border-hud-panel/30 w-full max-w-3xl max-h-[85vh] flex flex-col">

        {/* Header bar */}
        <div className="flex items-center justify-between px-4 py-3 border-b border-hud-panel/20 shrink-0">
          <HUDLabel className="text-hud-accent">LANDING PAGE PROMPT</HUDLabel>
          <button onClick={state === 'loading' ? handleCancel : onClose}
                  className="text-hud-panel/50 hover:text-hud-bg text-xs font-mono tracking-widest">
            {state === 'loading' ? 'CANCEL' : 'CLOSE'}
          </button>
        </div>

        {/* Content area — conditional on state */}
        {state === 'loading' && (
          <div className="flex-1 flex flex-col items-center justify-center gap-3 py-12">
            <div className="w-5 h-5 border-2 border-hud-accent/40 border-t-hud-accent animate-spin" />
            <span className="text-[10px] font-mono text-hud-panel/50 tracking-widest">
              SYNTHESIZING PROMPT FROM ALL CONVERSATIONS...
            </span>
          </div>
        )}

        {state === 'error' && (
          <div className="flex-1 flex flex-col items-center justify-center gap-3 py-12">
            <span className="text-[11px] font-mono text-red-400">{errorMsg}</span>
            <button onClick={handleRetry}
                    className="bg-hud-accent text-hud-fg px-4 py-1.5 text-[10px] font-mono font-bold tracking-widest">
              RETRY
            </button>
          </div>
        )}

        {state === 'done' && (
          <>
            {/* Scrollable prompt text */}
            <div className="flex-1 overflow-y-auto px-4 py-3">
              <pre className="text-[11px] font-mono text-hud-bg/85 leading-relaxed whitespace-pre-wrap">
                {promptText}
              </pre>
            </div>

            {/* Footer with copy button */}
            <div className="shrink-0 border-t border-hud-panel/20 px-4 py-3 flex items-center justify-between">
              <span className="text-[9px] font-mono text-hud-panel/50 tracking-widest">
                PASTE INTO BOLT / LOVABLE / CURSOR / V0
              </span>
              <button onClick={handleCopy}
                      className="bg-hud-accent text-hud-fg px-4 py-1.5 text-[10px] font-mono font-bold tracking-widest">
                {copyLabel}
              </button>
            </div>
          </>
        )}

      </div>
    </div>
    ```

    Export as `export default function LandingPromptModal`.
