## Codebase Patterns
- Active app dir is ROOT-LEVEL `app/` NOT `src/app/` — always edit `app/layout.tsx`, `app/globals.css`, `app/page.tsx`
- Tailwind v4 CSS-first: no tailwind.config.js; tokens go in `@theme {}` block in `app/globals.css`
- HUD color tokens: bg-hud-bg (#d2edea), bg-hud-fg (#1a2024), bg-hud-accent (#ebff00), bg-hud-panel (#b1dbd8)
- Font variables: --font-rajdhani (sans), --font-jetbrains-mono (mono); applied via CSS --font-sans and --font-mono in @theme
- Use `bg-hud-*`, `text-hud-*`, `border-hud-*` token classes — NOT hardcoded hex arbitrary values like `bg-[#1a2024]`
- Vertex AI route handlers: export const runtime = 'nodejs' (REQUIRED), reuse createVertex from @ai-sdk/google-vertex
- Prisma client: import from '@/lib/prisma' (singleton pattern)
- generateObject is DEPRECATED in ai@6.0.134 — use: import { generateText, Output } from 'ai' with output: Output.object({ schema })
- pptxgenjs: Node.js only — never import in client components or edge routes; use pptx.write({ outputType: 'nodebuffer' }) → Promise<Buffer>
- Binary PPTX response: new NextResponse(new Uint8Array(buffer), { headers: { 'Content-Type': 'application/vnd.openxmlformats-officedocument.presentationml.presentation', 'Content-Disposition': 'attachment; filename=...' } })
- server-only modules: import 'server-only' as first line in src/lib/slides/*.ts to prevent client bundle inclusion
