## Codebase Patterns
- Prisma client imported from `@/lib/prisma` (singleton with PrismaBetterSqlite3 adapter)
- Prisma types from `@/generated/prisma/client`
- Run `prisma generate` before `tsc --noEmit` in fresh worktrees — generated client won't exist
- Run `prisma migrate deploy` before `npm run build` in fresh worktrees — requires `.env` (not `.env.local`) since dotenv/config in prisma.config.ts loads `.env` by default
- Layout files own `h-screen`; page components inside them should use `h-full`
