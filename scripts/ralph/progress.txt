## Codebase Patterns
- Next.js scaffold: use temp dir (create-next-app rejects capital letters in cwd name), then cp -r /tmp/scaffold/. . then rm -rf node_modules && npm install (to fix symlinks)
- Branch setup: create-next-app overwrites .git — always run git checkout -b <branch> AFTER copying scaffold files
- Typecheck: `npx tsc --noEmit` (requires node_modules symlinks to be correct)
- Prisma 7: uses driver adapters — SQLite requires `@prisma/adapter-better-sqlite3` + `better-sqlite3`; PrismaClient constructor requires `{ adapter }` option (no-arg constructor is a type error)
- Prisma 7: PrismaClient generated to `src/generated/prisma/client.ts` — import from `@/generated/prisma/client` (not `@prisma/client`)
- Prisma 7: config in `prisma.config.ts` (not schema.prisma) — datasource URL set via `process.env["DATABASE_URL"]` loaded by `dotenv/config`
- SQLite db file lands at `./dev.db` (project root) — add `*.db` to .gitignore
- pdf-parse v2: use `PDFParse` class with `{ url: absolutePath }` constructor → `.load()` → `.getText()` (returns `{ pages: [{text, num}] }`)
- ts-node scripts with tsconfig `"module":"esnext"`: run with `--compiler-options '{"module":"commonjs"}'` to avoid ESM require() errors
- scripts/extract-docs.ts: run with `npx ts-node --skip-project --compiler-options '{"module":"commonjs"}' scripts/extract-docs.ts`
- server-only package throws when imported outside Next.js context (even in ts-node) — cannot use ts-node to verify modules that import server-only; verify via file size checks instead
- Context loader: import from `@/lib/context`, function `getSystemContext()` returns all docs joined with `\n\n---KNOWLEDGE BASE DOCUMENT---\n\n`
- Vertex AI model on socratoys project: use `gemini-2.5-flash` — gemini-2.0-flash and gemini-1.5-flash return 404; gemini-2.5-flash is available
- Vertex AI ADC: use GOOGLE_CLOUD_PROJECT=socratoys, GOOGLE_CLOUD_LOCATION=us-central1, GOOGLE_APPLICATION_CREDENTIALS pointing to ADC json
- All Vertex AI Route Handlers MUST have `export const runtime = 'nodejs'` — edge runtime breaks gcloud ADC auth
