## Codebase Patterns
- All Vertex AI routes use `export const runtime = 'nodejs'`
- Prisma client imported from `@/generated/prisma/client` (singleton at `src/lib/prisma.ts`)
- Generated Prisma client is gitignored at `src/generated/prisma` — run `npx prisma generate` after migrations
- Migration must be run from main working tree (worktree has no node_modules); copy migration.sql to worktree after
- Seed scripts use relative import `../src/lib/prisma` and must be run from main working tree
- Dev server (Next.js) locks SQLite dev.db — stop it before running `prisma migrate dev`
