## Codebase Patterns
- All Vertex AI routes use `export const runtime = 'nodejs'`
- Prisma client imported from `@/lib/prisma` (singleton)
- HUD components (HUDLabel, HUDPanel, etc.) exported from `@/components/hud`
- Vertex AI client initialized with `createVertex({ project, location })` from `@ai-sdk/google-vertex`
- Use `generateText` (not `generateObject`) for free-text generation; access result via `result.text`
- Route handlers use `params: Promise<{ id: string }>` pattern (Next.js 15 async params)
- `useRef` with function type needs explicit `undefined` initial value: `useRef<(() => void) | undefined>(undefined)`
