## Codebase Patterns
- Worktree has no node_modules or prisma client on first use — run `npm install && npx prisma generate` and `DATABASE_URL="file:./dev.db" npx prisma migrate deploy` before running tsc/build checks
- All Vertex AI routes use `export const runtime = 'nodejs'`
- Prisma client imported from `@/lib/prisma` (singleton pattern)
- HTTP streaming headers (X-Content-Type-Options, X-Accel-Buffering, Cache-Control) set on Response wrapping result.toTextStreamResponse()
